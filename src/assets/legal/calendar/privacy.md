# 《全民万年黄历通》隐私政策

最后更新日期：2026年9月26日

## 一、引言

上海卓瑞云创信息技术有限公司（"我们"）非常重视您的隐私保护。本隐私政策适用于我们的"全民万年黄历通"应用，描述了我们如何收集、使用、存储和共享您的个人信息。

## 二、我们收集的信息

为了向您提供日历、黄历和节气服务，我们可能会收集以下信息：

- **设备信息：**

  - **基本信息：** 设备型号、操作系统版本、设备标识符（IMEI、Android ID）
  - **Android ID 与 OAID（开放匿名设备标识符）：** 在您同意本隐私政策后，Android 客户端接入的穿山甲广告 SDK 可能在初始化、广告请求及运行过程中读取 Android ID、OAID；快手联盟 SDK 可能在广告初始化、请求及运行过程中读取 Android ID。上述标识符用于广告投放、广告监测归因、反作弊及异常流量识别。Android ID 通过 Android 系统接口读取，OAID 通过设备厂商提供的标识服务接口读取，具体方式、范围和提供方见第五节。读取可能发生在广告展示之前，不以您点击广告为前提。
  - **设备 MAC 地址：**

    - 收集目的：用于广告投放、广告效果统计、反作弊检测、用户行为分析
    - 收集方式：通过系统 API 自动获取设备的网络 MAC 地址
    - 收集范围：在您使用应用期间，通过第三方广告 SDK 自动收集
- **软件安装列表：**

  - Android 新版控制：黄历和天气功能不需要软件安装列表。新版在广告初始化前向穿山甲聚合 SDK 注入隐私控制，将应用列表读取设置为不允许，不提供自定义安装包名列表；优量汇的应用安装状态采集保持关闭。同意本隐私政策不会开启上述采集。该限制随新版 Android 客户端生效，较早版本及未采用该限制的 SDK 处理范围见以下原有披露与第五节。

  - 收集目的：用于广告定向投放、广告效果分析、防止欺诈行为、优化广告内容推荐
  - 收集方式：通过系统 API 获取设备上已安装的应用列表信息
  - 收集范围：在您使用应用期间，通过第三方广告 SDK 自动收集已安装应用包名信息
- **IP 地址：**

  - 收集目的：用于广告投放、广告效果监测与归因、反作弊及异常流量识别。
  - 收集方式：在您同意本隐私政策后，由我们接入的穿山甲广告 SDK、优量汇 Android SDK 通过 Android 系统网络接口自动读取设备 IP 地址。
  - 收集范围与触发场景：Android 客户端中，同意后的广告 SDK 初始化、广告请求及运行过程中可能读取，包括广告尚未展示时为广告服务进行的初始化和请求；不以您点击广告为读取前提。具体 SDK 的处理目的、方式和场景见第五节对应说明。
- **传感器列表及传感器信息：**

  - 收集目的：用于广告投放中的设备能力适配、广告交互支持及反作弊，识别异常设备环境和异常广告行为。
  - 收集方式：在您同意本隐私政策后，由接入的广告 SDK 通过 Android 系统传感器接口读取设备支持的传感器列表或特定类型传感器列表；在相应广告功能需要时读取传感器信息。
  - 收集范围与触发场景：包括设备支持的传感器类型，以及磁力、加速度、重力、陀螺仪等传感器信息；可能在同意后的广告 SDK 初始化、广告请求、加载、展示及运行过程中发生，不以广告已经展示或您点击广告为前提。优量汇 Android SDK、快手联盟广告 SDK、穿山甲广告 SDK、百度移动广告 SDK 的提供方、处理方式、各自的传感器类型和用途详见第五节。不同 SDK 的范围不相同：列表查询与测量数据分别按对应条目说明，不代表每家 SDK 都读取全部类型或完整列表。传感器列表表示设备支持的传感器类型，与持续读取传感器测量数据不同。
- **头像照片：** 您主动更换头像时，我们通过系统图片选择器仅访问您选择的照片，不读取整个相册。图片会在本机缩小、居中裁切并重新编码，去除原图的定位等附加信息；点击保存后才上传至我们的账号服务，用于展示个人头像。您可以重新选择或取消，未保存的预览不会更新服务器头像。头像文件存储于账号服务配置的对象存储，新的头像会关联到您的账号。
- **使用信息：** 应用使用情况、功能访问记录等
- **位置信息：** 用于城市天气。Android 和 iOS 新版客户端仅在您同意本隐私政策、主动点击“定位当前城市”并确认天气定位用途、授予系统前台位置权限后，按需请求一次近似位置。Android 通过系统 Geocoder 识别城市；iOS 通过 Apple Core Location 请求降低精度的位置，再使用 CLGeocoder 识别城市，即使您允许精确位置，天气功能也仅请求近似位置。iOS 的近似位置及其更新频率由系统决定，可能无法准确区分相邻城市或区县。打开首页、进入天气详情或城市选择页、切换页面、回到前台、搜索或手动选择城市以及刷新天气均不会自动获取位置。同一应用会话内成功识别的城市5分钟内复用，重复点击不重新取位；定位进行中复用同一请求，两次取位请求至少间隔1分钟，失败或取消也受该间隔限制。不为天气请求精确定位、后台定位或持续位置监听。较早版本可能在页面进入或回到前台时请求位置；上述调整随新版客户端生效。系统解析服务可能联网处理经纬度：Android 由设备提供的系统服务实现，iOS 使用 Apple 地址解析服务；我们不在本机持久保存定位经纬度。我们的服务器仅接收国家、省、市、区等粗粒度地址字段，不接收用户原始经纬度、街道门牌或完整地址，不记录位置轨迹。服务器以城市目录中的代表点或经核验的供应商地点编号向 WeatherAPI.com 请求城市天气，不向 WeatherAPI.com 发送您的账号、手机号码或原始定位坐标。当前城市与最近选择仅保存在本机，天气在本机仅作内存缓存。我们不为天气申请后台定位；拒绝授权、定位失败或系统地址解析不可用时，您仍可手动选择城市，亦可随时在系统设置撤销位置权限。
- **日历事件：** 用于提供提醒功能（仅存储在本地设备上）。

## 三、信息使用目的

我们使用收集的信息主要用于：

- 提供日历、黄历和节气等核心功能
- 提供个性化服务
- 改善用户体验
- 进行数据分析
- 保障应用安全
- 提供个性化的节日提醒和重要日期提示
- 处理应用内购买交易（如适用）

## 四、信息保护措施

我们采取以下措施保护您的个人信息安全：

- 采用加密技术保护数据安全
- 严格限制数据访问权限
- 定期进行安全审计
