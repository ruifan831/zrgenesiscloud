# 提词器大师隐私政策

> 版本：1.1 · 更新日期：2026年9月13日

上海卓瑞云创信息技术有限公司（以下简称“我们”）提供提词器大师 iOS 和 Android 应用。本政策说明使用写稿、提词、拍摄及可选账号、福利功能时，个人信息如何被处理。请结合[用户协议](/legal/ticidashi/terms)阅读。

## 一、应用内作品与账号数据

<strong>稿件、录制视频与个人账号资料是不同类型的数据。</strong>基础写稿、提词与拍摄可以在不登录时使用。稿件与视频保存在当前设备的应用内，不会因拍摄完成自动进入手机相册，也不会自动上传为云端作品。

您选择“保存到相册”、导出或系统分享时，应用才将所选文件交给系统或您选择的接收方。导出的副本由相册、文件管理器或接收方管理。删除应用内视频不会同步删除这些副本。

平台账号资料及钱包由平台账号体系管理。修改账号资料、注销账号可能影响您使用同一账号登录的其他平台应用；应用内稿件与视频不会因此成为其他应用可访问的云端作品。

## 三、设备权限

- <strong>摄像头、麦克风</strong>：仅用于您启动的录制功能。可在系统设置撤回权限。
- <strong>相册添加权限（iOS）</strong>：在您选择保存视频到相册时申请。拒绝后原视频仍保存在应用内。
- <strong>照片选择和文件选择</strong>：通过系统选择器读取您选定的头像或文件；无需读取全部相册或全部文件。
- <strong>跟踪授权（iOS）</strong>：系统授权用于涉及跨应用跟踪的广告能力。您可选择要求 App 不跟踪，并在系统设置管理授权；拒绝不影响基础创作。

广告 SDK 的数据处理还见下一节。权限授权不意味着我们可以处理与对应功能无关的信息。

## 四、第三方服务与 SDK 清单

我们通过穿山甲 GroMore 聚合提供广告服务。聚合服务与参与投放的广告平台是不同的服务提供方，具体清单如下。我们不会将您的稿件、录制视频或麦克风录音提供给广告平台用于广告投放。

广告 SDK 在您同意本政策后按广告功能需要初始化，集成的下游广告 SDK 可能随聚合初始化处理设备信息，并非只有点击广告后才处理。数据由 SDK 在设备端采集并通过网络传输给相应提供方。具体广告源由投放配置及广告请求决定，单次请求不代表所有平台均提供广告。

以下信息范围受操作系统、授权状态和实际 SDK 配置限制。iOS 广告标识符 IDFA 仅在获得系统跟踪授权后可用；拒绝跟踪不影响基础创作。未获得相应权限时，不读取该权限保护的信息。

## 五、保存、删除与安全

应用内稿件保留至您删除或卸载；已删除稿件可在“已删除稿件”中保留 7 天以便恢复。<strong>视频确认删除后不可恢复。</strong>卸载应用可能移除应用内作品，请提前导出。

账号、奖励和提现记录按提供服务及履行法定义务所需的最短必要期限保存。账号注销不等于所有交易、安全或依法留存的记录立即从备份中删除；超过保存目的或法定期限后，我们将删除或匿名化。法律要求继续保存的信息会限制为必要的存储和安全保护用途。

我们采取访问控制、身份认证、传输保护等安全措施。发生个人信息安全事件时，会采取补救措施，并依法履行告知和报告义务。

关于网络服务的数据存储地区、服务商和可能涉及的跨境处理，您可以通过本政策联系渠道查询；如发生依法需要另行告知或单独同意的处理，我们将在开展前履行相应程序。

## 六、您的权利

您可以在“我的”中查看账号、修改资料、移除头像，或在“注销平台账号”中提交注销申请；提现和未结清事项可能需要先处理。退出登录不会删除应用内作品。

您也可请求查阅、复制、更正、补充或删除个人信息，撤回同意，了解处理规则，或对处理提出异议。我们会核验必要身份信息后依法处理并反馈。撤回同意不影响撤回前基于同意开展的处理。

## 七、未成年人

未成年人应在监护人指导下阅读政策并使用适龄功能。涉及不满十四周岁儿童的个人信息，我们将依法取得监护人同意并采取专门保护。监护人发现未经同意处理儿童信息时，可联系我们请求处理。福利、抽奖和提现须符合活动公布的参与资格。

我们会在本页面更新政策。涉及处理目的、方式或信息种类等重大变化时，会在应用内以适当方式告知，并在依法需要时重新征求同意。
