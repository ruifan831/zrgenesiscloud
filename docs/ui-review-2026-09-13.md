# 官网 UI 评估与完善 · 2026-09-13

## 评估范围与方向

实际浏览 https://www.zrgenesiscloud.com/ 的首页、当前公开 API 列出的两款产品、联系、隐私汇总、独立协议与邀请页面；另核对源代码路由及提词器旧入口。以下是视觉与使用体验评估，不是法律正文审核。

沿用项目既有 Apple 产品画廊参考和 SF Pro 系统字体。使用场景是用户在日常明亮环境下通过手机查找应用，或在桌面查看下载和协议：采用浅色首屏、真实应用图标、深浅交替产品区，减少空白占屏并保持蓝色动作入口。

## 数据与内容待办

- 公共 API 实际只返回 `huangli`、`crewpilot`。未凭本地图标或旧 PRD 伪造更多在售产品。
- 黄历详情 API 的 `privacy_url`、`terms_url`、功能图与详情图为空。已在隐私汇总提供现存 `/privacy/calendar` 正文入口；运营应补齐该产品的正式营销配置。
- 班管家无下载渠道；界面如实显示暂未提供下载。需要在后台补齐正式渠道。
- `/legal/{privacy,terms,sdk-list,pii-collection,minor-protection}` 中仍有 `{{...}}` 字段和“草案/待填字段清单”，需业务核实后发布完整正文，本次不擅自补日期或声明。
- 名为公司通用隐私声明的 `/privacy-policy` 现有正文实际上以黄历 App 为主体，需要确认文档定位。未改写正文。
- 正式 ICP 编号仍为空，需要真实编号后填入 environment；隐藏占位不代表备案事项已完成。
- 生产 `/privacy` 403 的原因与构建生成 `privacy/teleprompter/` 目录相符：`try_files $uri $uri/ /index.html` 命中目录。已在 `docs/nginx/public-site-privacy.conf` 增加 `/privacy` 和 `/privacy/` 精确 SPA 入口；需要部署合并并执行 `nginx -t` 后重载。本次未操作生产服务器。
