# 班管家（CrewPilot）隐私政策

> 生效日期：2026-06-12 · 上次更新：2026-10-24

班管家 CrewPilot（以下简称"我们"或"本服务"）由**上海卓瑞云创信息技术有限公司**（以下简称"卓瑞云创"）开发并运营，卓瑞云创为本服务的开发者与个人信息处理者。本服务非常重视用户的个人信息保护。本《隐私政策》说明我们在你使用本服务的过程中如何收集、使用、存储、共享和保护你的个人信息，以及你享有的相关权利。请在使用本服务前仔细阅读并充分理解本政策的全部内容。

## 1. 我们收集的信息

- **账号信息**：在你注册和登录时，我们会收集你的邮箱或手机号、密码（加密存储）、昵称与头像；如使用 Passkey / Apple / 微信登录，仅获取必要的标识信息。
- **组织与排班信息**：你在组织中创建的员工档案、可用时间、班次模板与排班结果，仅在所属组织内部共享，由组织所有者及管理员查看。
- **设备与日志信息**：包括设备型号、操作系统版本、浏览器或 App 版本、访问时间、IP 地址（去标识化）等，用于保障服务安全与故障排查。
- **设备标识符与广告反作弊信息**：在你同意本隐私政策后，为了在应用内展示激励视频与开屏广告，广告 SDK 可在**初始化、广告请求及运行过程中**通过系统接口读取 **Android ID**、**OAID**、**WLAN MAC 地址**、**IMEI（仅 Android 10 以下）**、**加速度计 / 陀螺仪等传感器数据**。

  - **目的**：广告归因、异常流量识别与反作弊、频次控制
  - **方式**：由我们接入的第三方广告 SDK 在初始化、广告请求及运行过程中按需通过系统接口自动读取；**未同意本政策前，广告 SDK 不会初始化、不会触发上述读取**
  - **范围**：仅上报至对应广告 SDK 服务器用于广告业务；本服务自身服务器不留存原始设备标识与传感器数据
- **已安装应用信息**：在你同意本隐私政策后，为提供广告投放、广告归因及反作弊服务，我们接入的第三方广告 SDK 可能在初始化、广告请求及运行过程中，通过 Android 系统接口查询已安装应用信息（软件安装列表），包括应用包名及具有桌面启动入口的应用。查询范围受系统版本、应用可见性规则及权限限制。具体 SDK 及处理规则见 [第七节](/legal/crewpilot/privacy/#third-party-sdks)和 [《第三方 SDK 清单》](https://crewpilot.zrgenesiscloud.com/legal/sdk-list)。
- **通知凭据**：在你授权后，我们会保存推送 token / 邮件地址，用于向你发送排班变更、邀请加入等通知。

## 2. 我们如何使用信息

我们仅在以下场景内使用你的信息：

- 提供并维护排班、考勤、协作等核心功能。
- 向你发送服务相关通知、安全提醒以及你订阅的内容。
- 分析使用情况以改进产品体验（仅使用聚合数据，无法识别到具体个人）。
- 预防欺诈、滥用与违反法律法规的行为，保护用户与平台权益。

## 3. 信息的共享与披露

我们不会向任何第三方出售你的个人信息。仅在以下情形下，我们可能共享必要的信息：

- 经你明确同意后向你指定的接收方分享。
- 同一组织内部协作所必需（如向管理员展示员工档案）。
- 为提供服务而委托的可信服务商（如云存储、推送、短信、邮件），并通过协议要求其遵循等同标准的保护义务。
- 法律法规要求、司法或行政机关依法提出的强制要求。

## 4. 信息的存储与安全

我们采用业界通行的加密传输（TLS）、加密存储、访问审计与最小权限策略来保护你的信息。除非法律法规另有规定或为满足合规、争议解决之必要，我们仅在实现处理目的所必需的最短时间内存储你的信息。

## 5. 你的权利

- 访问与复制：可在"我的"页面查看并导出你的账号与排班数据。
- 更正：你可随时修改昵称、头像与可用时间等资料。
- 删除：你可按下方“账号注销流程与规则”申请注销账号；注销后我们会按合规要求清除或匿名化你的个人信息。
- 撤回授权：你可关闭推送、定位等系统级授权；部分功能可能因此不可用。
- 投诉举报：如对个人信息处理有疑问，可通过下方联系方式与我们沟通。

### 5.1 账号注销流程与规则

**应用内注销入口：登录班管家 App → 底部“我的” → 向下找到并点击“注销账号”。** Android 和 iOS 均提供此入口；微信小程序也可从“我的 → 注销账号”进入。

1. **阅读注销提示**：进入“注销账号”页面，阅读账号注销后果和数据删除提示，确认已妥善保存需要保留的信息。
2. **验证本人身份**：点击“获取验证码”。系统优先向账号绑定的手机号发送验证码；未绑定手机号但绑定邮箱的，向该邮箱发送验证码。输入收到的验证码。
3. **提交并再次确认**：Android 点击“确认注销账号”，在“最后一次确认”弹窗中点击“仍要注销”；iOS、小程序按页面提示继续并再次确认。最后确认前，你可以取消并退出注销流程。
4. **完成注销**：验证码校验通过且满足下列条件后，系统执行注销；成功后退出登录，该账号无法再用于登录或恢复原有数据。若页面提示失败或存在待处理事项，说明注销尚未完成，请按提示处理后重试，或通过下述邮箱联系我们。

**注销前需处理的事项：**

- 如你是某个仍有其他成员的组织所有者，请先转让组织所有权或解散该组织，避免影响其他成员；只有你自己的组织会在注销时一并关闭。
- 如有待审核、已通过但尚未打款的提现申请，请先等待处理完成或撤销申请；如账户仍有现金余额，请先完成提现，使现金余额归零。
- 请在最后确认前核对需保留的信息及账号内的金币、奖励等权益；注销后原账号及关联权益记录无法恢复。

**注销后的信息处理**：注销成功后，我们停止向该账号提供服务，并按法律法规要求删除或匿名化与账号相关的个人信息。账号及被删除的数据不可恢复，重新注册不会恢复原账号数据。法律法规规定必须保留的信息，或技术上暂时难以删除的信息，仅在必要范围内存储并采取安全保护措施，停止用于其他目的，待保留期限届满或具备删除条件后处理。退出登录、卸载 App 或停用一段时间均不等于注销账号。

**无法自助注销时的联系渠道**：如无法登录、无法接收验证码、账号未绑定手机号或邮箱，或你使用的网页端没有自助注销入口，可发送邮件至 [support@zrgenesiscloud.com](mailto:support@zrgenesiscloud.com)，申请协助注销。邮件主题建议为“班管家账号注销申请”，正文说明需注销的账号标识（账号 ID、已绑定手机号或邮箱）、遇到的问题及可联系的方式；请勿发送密码或短信、邮件验证码。我们会在核验账号归属后协助处理，并在收到请求之日起 **15 个工作日内回复处理情况**；如需补充核验或处理前述事项，会告知你原因和后续步骤。该回复期限不表示发送邮件后账号会自动注销。

## 6. 未成年人保护

本服务面向用人单位与成年劳动者。如发现未满 14 周岁的儿童在未经监护人同意的情况下使用本服务，我们将在核实后立即停止处理并删除相关信息。
